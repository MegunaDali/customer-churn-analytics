# Customer Churn Analytics & Prediction

## Project Overview

This project develops an end-to-end customer churn analytics solution using telecom customer data.

The goal is to identify customers who are at risk of leaving, understand the factors associated with churn, and translate predictive insights into actionable customer retention strategies.

## Business Questions

- What proportion of customers churn?
- What characteristics distinguish churners from non-churners?
- Which customer behaviors are associated with churn?
- Can customer churn be predicted using historical customer data?
- Which customers should be prioritized for retention?
- What actions could the business take to reduce churn?

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Power BI
